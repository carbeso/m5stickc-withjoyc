# M5StickC Plus & MiniJoyC 掌上型紓壓與感測工具旗艦套件 (13-in-1 Fidget & Sensor Suite)

[English](README.md) | [繁體中文](README.zh-TW.md)

一款專為 **M5StickC Plus** 搭配 **MiniJoyC HAT** 擴充模組量身打造的掌上型 **十三合一 (13-in-1)** 紓壓互動玩具與感測工具韌體系統。
整合直向 IPS 螢幕全域雙緩衝防閃爍視覺、無源蜂鳴器機械音效、SK6812 全彩氛圍燈、雙軸實體搖桿機械手感、MPU6886 體感甩動操控與多維物理熵源核心，打造厚實、清脆、流暢且沉浸感十足的極致掌上微動力學體驗。

## 🛠️ 硬體規格與連接配置

- **主控平台**：M5StickC Plus
  - **核心晶片**：ESP32-PICO-D4 (雙核 240MHz, 320KB SRAM, 4MB Flash, 2.4GHz Wi-Fi & BLE)
  - **螢幕**：1.14 吋 ST7789v2 IPS TFT LCD (135 × 240 像素，直向模式)，具備全域 63.3KB 雙緩衝畫布 (`g_canvas`)
  - **電源管理**：AXP192 (內建電量計、充電檢測、動態背光調節)
  - **姿態感測**：MPU6886 6 軸運動感測器 (3 軸加速度 + 3 軸陀螺儀)
  - **聲音輸入**：SPM1423 數位 PDM 麥克風 (CLK: GPIO 0, DATA: GPIO 34)
  - **音效輸出**：GPIO 2 內部無源蜂鳴器 (PWM 音效引擎)
  - **正面按鍵**：Button A (GPIO 37)
  - **側面按鍵**：Button B (GPIO 39)
- **擴充底座**：M5Hat MiniJoyC
  - **協同晶片**：STM32F030F4P6 (I2C 位址 `0x54`，SDA: GPIO 0, SCL: GPIO 26)
  - **控制搖桿**：雙軸 8-bit 類比搖桿 (X: -128~127, Y: -128~127，死區設為 25)
  - **搖桿按鍵**：下壓微動開關 (硬降 / 確認鍵)
  - **氛圍燈效**：內建 1 顆 SK6812 全彩 RGB LED
  - **內建電池**：200mAh 聚合物鋰電池 (總電量達 320mAh)

## 🕹️ 全域系統操作守則

```
                           [開機畫面: FIDGET TOY / Ultimate Suite]
                                             │
                                             ▼
                             ┌───────────────────────────────┐
                             │    全域主選單 (Fidget OS)      │ <─── 任何遊戲中長按 Button B (> 0.5s)
                             │ 3 卡片可捲動視窗 (搖桿上下推) │
                             └───────────────┬───────────────┘
           ┌──────────────┬────────────┼────────────┬──────────────┐
           ▼              ▼            ▼            ▼              ▼
      🎲 骰子盒       🃏 撲克      🎱 八號球    🎡 輪盤       🎰 老虎機
           │              │            │            │              │
           ▼              ▼            ▼            ▼              ▼
      🪙 擲硬幣      ✌️ 猜拳對決   🔢 1A2B猜數字 ⏱️ 待機時鐘    🔬 感測器實驗室
                                       ┌────────────┴──────────────┐
                                       ▼                           ▼
                                  📊 頻譜分析儀               ⏳ 重力流沙 / 🧱 俄羅斯方塊
```

### 1. 主選單導航
- **搖桿上下推**：在 13 款卡片間平滑滾動（支援首尾循環導航，右側具備動態滑塊捲動條）。
- **Button A / 搖桿中心鍵**：確認進入所選遊戲或工具。
- **搖桿左右推**：循環調節螢幕背光亮度（35% → 70% → 100%）。
- **短按 Button B**：一鍵切換全域聲音開關（`[SND ON]` / `[MUTE]`）。
- **機身大力甩動**：隨機抽取一款遊戲或工具進入。
- **頂部狀態列**：即時顯示電池電壓換算百分比（如 `85%`）與充電狀態（如 `+95%`）。
- **自動待機休眠**：選單閒置無操作超過 60 秒，自動切換至低功耗螢幕保護畫面。

### 2. 遊戲內通用手勢
- **長按 Button B (> 500ms)**：立即退出當前場景，安全釋放週邊並返回主選單。
- **下拉搖桿維持 (joyY > 35)**：在輪盤、老虎機、硬幣、猜拳中進入**持續全速飛轉**模式；在俄羅斯方塊中加速下落；放開搖桿後進入自然衰減與煞車時序。
- **體感大力甩動**：任何時候用力甩手機身即可觸發洗牌、擲骰、拋幣、流沙爆散動態。

## 💻 快速上手與本地開發

本專案使用標準 **PlatformIO** 進行依賴管理、編譯與燒錄。

### 1. 環境需求
- 安裝 [VS Code](https://code.visualstudio.com/) 與 **PlatformIO IDE** 擴充套件。
- 實機連接：使用 Type-C 傳輸線連接 M5StickC Plus，確認裝置管理員出現 `CH9102` 或 `CP210x` 虛擬序列埠（例如 `COM3`）。

### 2. 下載專案
```bash
git clone https://github.com/carbeso/m5stickc-withjoyc.git
cd m5stickc-withjoyc
git checkout dev  # 建議於 dev 或獨立分支進行功能開發
```

### 3. 編譯與燒錄常用指令
在專案根目錄終端機執行：

```bash
# 1. 僅執行編譯檢查 (驗證語法與依賴庫，確保 exit code 0)
pio run

# 2. 編譯並燒錄至裝置 (自動偵測序列埠)
pio run -t upload

# 3. 指定序列埠燒錄
pio run -t upload --upload-port COM3

# 4. 開啟序列埠除錯監視器 (Baud rate: 115200)
pio device monitor -b 115200
```

## 📜 開發規範與守則

- **分支紀律**：
  - 嚴禁直接在 `main` / `master` 分支提交或推送。
  - 日常功能開發與文件更新必須在 `dev` 或 `feature/...`、`docs/...` 分支執行。
  - 每次提交前務必於本地執行 `pio run` 驗證 exit code 為 0。
  - 嚴禁使用 `git add .` 或 `git add -A`，提交時精確指定具體檔案路徑。
