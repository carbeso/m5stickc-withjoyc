# M5StickC Plus 與 MiniJoyC 掌上型紓壓玩具遊戲規格書 (Game Design & Technical Specs)

本規格書針對 **M5StickC Plus** 搭配 **MiniJoyC HAT** 擴充底座，量身規劃四款經典且具備深度感官回饋（視覺、聽覺、觸覺、體感）的掌上型紓壓遊戲。本文件詳細定義遊戲規則、小螢幕佈局、中文字體顯示評估、控制介面與硬體回饋映射，作為後續韌體開發與燒錄之最高指導規範。

---

## 1. 系統硬體環境與限制回顧

| 硬體元件 | 規格參數 | 遊戲互動用途 |
| :--- | :--- | :--- |
| **螢幕 (ST7789v2)** | 1.14 吋 TFT LCD（解析度 135 × 240，260 PPI） | 遊戲主畫面、動畫幀、數值結果呈現 |
| **操作搖桿 (MiniJoyC)** | 雙軸類比搖桿（I2C 0x54，X/Y 偏移量 -128~127） | 選單切換、數值微調、抽牌切牌、旋轉施力 |
| **搖桿按鍵 (Joy Button)** | 搖桿垂直下壓微動開關 | 確認、擲骰、翻牌、拉霸觸發 |
| **實體按鍵 A** | M5StickC 正面大按鍵 (GPIO 37) | 主要動作觸發鍵（同搖桿按鍵） |
| **實體按鍵 B** | M5StickC 右側面功能鍵 (GPIO 39) | 全域選單呼叫、返回上層、模式切換 |
| **姿態感測 (MPU6886)** | 6 軸加速度計與陀螺儀 (內部 I2C 0x68) | 甩動擲骰、翻轉揭牌、劇烈搖晃占卜 |
| **全彩氛圍燈 (SK6812)** | MiniJoyC 內建 1 顆 3535 RGB LED (I2C 0x40) | 遊戲情境燈效、大成功閃爍、結果色彩映射 |
| **無源蜂鳴器 (Buzzer)** | GPIO 2 PWM 驅動 | 擬真機械點擊聲、骰子滾動聲、轉盤嗒嗒聲 |

## 2. 螢幕尺寸與文字顯示評估 (1.14" 135×240)

在 1.14 吋 135×240 的小螢幕上開發文字互動遊戲，需特別注意字體清晰度與資訊密度：

### 2.1 中文字型顯示可行性評估
1. **螢幕物理特性**：
   - 135×240 像素在 1.14 吋面積下，像素密度高達 **260 PPI**，線條十分細膩，不會有粗糙鋸齒。
2. **字級與字數容量計算**：
   - **直向模式 (135 寬 × 240 高)**：
     - 若採用 **16×16 點陣字**：每行最多容納 **8 個中文字**（寬度耗費 128px，邊距左右各 3px）；可垂直排列 8~10 行。
     - 若採用 **12×12 點陣字**：每行最多容納 **10 個中文字**（寬度耗費 120px）；適合次要提示或說明。
   - **橫向模式 (240 寬 × 135 高)**：
     - 若採用 **16×16 點陣字**：每行可容納 **14 個中文字**，可排 4~5 行。
3. **記憶體與字庫策略 (ESP32 4MB Flash)**：
   - 若引入幾萬字的完整繁體中文字庫（如全套思源黑體），會消耗數 MB 快閃記憶體。
   - **最佳化策略**：**採用「限定辭庫字型抽取 (Font Subsetting)」**。
     - 將四款遊戲中所有用到的繁體中文字（約 150~200 個獨立字元）萃取成自訂點陣字庫（Binary Bitmap Array），體積僅需 **3~4 KB**，直接常駐快閃記憶體。
4. **設計結論**：
   - **完全可行且閱讀體驗極佳**。
   - 配合「**大字號 16×16 繁中精練短句 + 英文關鍵字輔助**」，視覺既現代又直覺，長輩與年輕玩家都能一目了然。

## 3. 四大遊戲核心規格與玩法設計

### 遊戲一：多面骰子盒 (Dice Roller) 🎲

滿足 TRPG（D&D、COC）、桌遊與日常決策的萬用電子擲骰神器。

```
+-----------------------------+
| [DICE BOX]        d20 x 2   | <- 頂部狀態列
|                             |
|    +-------+   +-------+    |
|    |  19   |   |  20!  |    | <- 骰子視覺圖 (高對比外框)
|    +-------+   +-------+    |
|                             |
|      TOTAL: 39 (CRIT!)      | <- 總合統計與大成功提示
|  [SHAKE] or [PRESS] to Roll | <- 提示操作
+-----------------------------+
```

#### 1. 遊戲規格
- **骰子面數 (Die Type)**：`d4`、`d6`、`d8`、`d10`、`d12`、`d20`、`d100`（百分骰）。
- **骰子數量 (Quantity)**：可選 `1` 至 `6` 顆（例如 1d6、3d6、2d20、1d100 等）。
- **特殊規則判定**：
  - **大成功 (Critical Hit)**：d20 擲出 20，觸發全螢幕彩虹爆裂光效與勝利蜂鳴音。
  - **大失敗 (Fumble)**：d20 擲出 1，觸發暗紅警示燈與低沉哀鳴音。
  - **統計功能**：當數量 ≥ 2 顆時，自動計算顯示總合（SUM）、最大值（MAX）與最小值（MIN）。

#### 2. 介面與操作
- **待機與設定介面**：
  - 螢幕上方常駐「面數」與「數量」調節標籤。
  - **搖桿左右撥動**：切換面數（d4 ↔ d6 ↔ d8 ↔ d10 ↔ d12 ↔ d20 ↔ d100）。
  - **搖桿上下撥動**：增加 / 減少骰子顆數（1 ~ 6 顆）。
- **擲骰觸發**：
  - **按鍵觸發**：按下搖桿中心鍵或正面 Button A。
  - **體感甩動 (IMU)**：**單手拿著裝置用力晃動**，陀螺儀偵測瞬時角速度 > 250 deg/s 立即觸發擲骰！

#### 3. 視覺與回饋
- **動畫歷程**：擲骰時進行約 0.6 秒的亂數高速跳動動畫，伴隨骰子邊框旋轉微動效，隨後平滑煞車定格。
- **排版佈局**：
  - 1 顆：中央超大骰子幾何輪廓（正二十面體/六面體線條）+ 巨大字體。
  - 2~3 顆：橫向排列並列顯示。
  - 4~6 顆：2×2 或 2×3 矩陣整齊陳列，底部緊湊顯示總計。
- **RGB 氛圍燈**：滾動時七彩流光旋轉；停定時若總點數高於平均值亮綠光，低於平均值亮藍光，大成功亮爆閃白光。
- **蜂鳴器**：滾動時發出模擬木盒擲骰的「噠、咯、咯、噠」連續撞擊聲，定格時發出清脆鈴響。

### 遊戲二：幸運撲克抽牌 (Card Shuffler & Draw) 🃏

隨機抽取命運紙牌，支援聚會抽籤、決定懲罰與比大小。

```
+-----------------------------+
| [POKER]       DECK: 53/54   | <- 剩餘牌數
|      .-----------------.    |
|      | A               |    |
|      |   ♠             |    |
|      |      ♠ ♠        |    | <- 翻開的撲克牌牌面
|      |             ♠   |    |
|      |               A |    |
|      '-----------------'    |
|  [UP] Draw  [CLICK] Joker   |
+-----------------------------+
```

#### 1. 遊戲規格
- **標準牌庫**：四種花色（黑桃 ♠、紅心 ♥、方塊 ♦、梅花 ♣）各 13 張（A、2~10、J、Q、K），共 52 張。
- **鬼牌選項 (Joker Option)**：
  - 可於選單設定是否加入鬼牌：
    - `OFF`：標準 52 張。
    - `ON`：加入 2 張鬼牌（紅色彩色大鬼牌 Big Joker、黑色小鬼牌 Little Joker），共 54 張。
- **抽牌機制 (兩種模式可選)**：
  - **單抽無限洗牌 (Quick Draw)**：每次抽牌皆從完整洗好的牌堆抽出一張，抽完立即隨機回洗。
  - **牌堆銷牌模式 (Deck Mode)**：模擬真實發牌，每抽一張牌庫少一張，牌面顯示「剩餘牌數」；抽完時需手動或自動「洗牌 (SHUFFLE)」。

#### 2. 介面與操作
- **設定與切換**：
  - 搖桿向下長推 1 秒：進入/切換「鬼牌加入開關 (Joker: ON / OFF)」。
  - 搖桿左右推：切換抽牌模式（單抽回洗 / 牌堆連續銷牌）。
- **抽牌與翻牌**：
  - **搖桿向上推**：從牌堆上方推發一張暗牌（顯示精緻撲克牌背菱格紋）。
  - **按鍵翻牌**：按下搖桿中心鍵或 Button A，觸發 3D 翻轉動畫翻開牌面。
  - **體感翻牌 (IMU)**：將裝置螢幕朝下覆蓋在桌上，再迅速翻轉向上，直接揭示底牌！
  - **重新洗牌**：雙擊 Button A 立即重置並洗牌。

#### 3. 視覺與回饋
- **牌面呈現**：
  - 四角點數與花色清晰標記。
  - 紅心 ♥ 與方塊 ♦ 採用鮮豔正紅色，黑桃 ♠ 與梅花 ♣ 採用深邃純黑色。
  - 抽到鬼牌時，全螢幕亮起小丑面具圖標與彩虹字樣。
- **RGB 氛圍燈**：抽到紅色花色時發出溫暖紅光，抽到黑色花色時發出冷白/淡藍光，抽到鬼牌時發出極光動態漸層。
- **蜂鳴器**：推牌時發出滑順「刷～」的紙牌摩擦聲，翻牌瞬間發出清脆俐落的「啪」聲。

### 遊戲三：神秘八號球 (Magic 8-Ball) 🎱

經典占卜玩具，為你解答心中的猶疑與困惑。

```
+-----------------------------+
|           .---.             |
|          /     \            |
|         |  (8)  |           | <- 待機狀態：經典黑球 8 號
|          \     /            |
|           '---'             |
|   [SHAKE TO ASK QUESTION]   |
+-----------------------------+
              ↓ (晃動後浮現)
+-----------------------------+
|          / \   / \          |
|         /   \ /   \         |
|       /======▲======\       | <- 深藍色浮動三角形視窗
|      |   大 吉 大 利  |      | <- 繁體中文 16x16 核心籤文
|      | (DEFINITELY) |      | <- 英文對照輔助詞
|       \=============/       |
+-----------------------------+
```

#### 1. 遊戲規格
- **解答詞庫規劃（24 種精選占卜籤詩，分成三大象限）**：
  - **肯定與大吉 (Positive - 10 款)**：
    1. 「大吉大利」(Definitely)
    2. 「毫無疑問」(Without a doubt)
    3. 「前景光明」(Outlook good)
    4. 「勇敢前行」(Go for it)
    5. 「勝券在握」(Signs point to yes)
    6. 「絕無問題」(Most likely)
    7. 「勢在必行」(Yes, absolutely)
    8. 「即刻行動」(Act now)
    9. 「心想事成」(It is certain)
    10. 「順其自然」(Flow with it)
  - **猶豫與未定 (Neutral / Uncertain - 7 款)**：
    1. 「靜觀其變」(Wait and see)
    2. 「霧裡看花」(Reply hazy, try again)
    3. 「稍後再問」(Ask again later)
    4. 「遵循直覺」(Trust your gut)
    5. 「不可言說」(Cannot predict now)
    6. 「專注當下」(Concentrate and ask)
    7. 「未成定數」(Better not tell now)
  - **否定與勸退 (Negative - 7 款)**：
    1. 「別抱期望」(Don't count on it)
    2. 「前景堪憂」(Outlook not so good)
    3. 「切勿輕舉」(My reply is no)
    4. 「休要強求」(Very doubtful)
    5. 「絕無可能」(My sources say no)
    6. 「換個方向」(Change your way)
    7. 「時機未到」(Not the right time)

#### 2. 介面與操作
- **占卜流程**：
  1. 待機時螢幕中央為一顆懸浮的黑色 8 號球，提示「默念問題，搖晃解惑」。
  2. 玩家在心中默想是非題（Yes/No 問題），隨後**用力甩動機身**或**長按搖桿中心鍵**。
  3. 螢幕出現藍色液體翻騰動畫，中央浮現藍色二十面體浮牌。
  4. 顯示繁體中文大字籤詩（16×16 中文）與英文副標。
- **語言模式切換**：
  - 搖桿左右推：切換【繁體中文優先】、【英文優先】、【中英雙語並陳】模式。

#### 3. 視覺與回饋
- **文字排版優勢**：四字成語或短詞（如「大吉大利」、「別抱期望」）在 135 寬度下居中排版極具視覺衝擊力，閱讀輕鬆不吃力。
- **RGB 氛圍燈**：
  - 肯定類籤詩：綠色 / 金黃色呼吸慢閃。
  - 中立類籤詩：神秘紫 / 天空藍柔和呼吸光。
  - 否定類籤詩：赤紅色短暫警示閃爍後轉深暗。
- **蜂鳴器**：晃動時發出咕嘟咕嘟的冒泡液體聲，籤文浮出瞬間發出空靈悠長的「叮～～」神秘音效。

### 遊戲四：幸運俄羅斯輪盤 (Lucky Roulette) 🎡

將經典歐式輪盤與指尖轉盤結合，支援隨機決策、幸運號碼與紅黑對決。

```
+-----------------------------+
| [ROULETTE]        BET: RED  | <- 頂部狀態與押注
|   .---------------------.   |
|   | 24 | [27] | 13 | 36 |   | <- 水平號碼捲軸 (刻度帶動畫)
|   '---------------------'   |
|            ▲                | <- 指標瞄準停定號碼
|                             |
|       ★ 27 RED (ODD) ★      | <- 巨幅號碼、顏色與奇偶屬性
|  [PULL] Spin  [JOY L/R] Bet |
+-----------------------------+
```

#### 1. 遊戲規格
- **輪盤規則**：採用標準歐式單零輪盤（European Roulette），共 37 個號碼：
  - `0`：綠色（Green，莊家幸運色）。
  - `1 ~ 36`：18 個紅色號碼、18 個黑色號碼。
- **決策與趣味押注玩法**：
  - **自由旋轉模式 (Free Spin)**：日常決定幸運數字、分組抽籤或隨機決策。
  - **紅黑預測挑戰 (Red / Black / Green Bet)**：
    - 轉動前可透過搖桿快速選擇押注：`RED`、`BLACK` 或 `GREEN (0)`。
    - 停定時比對結果，若押中則觸發彩帶粒子爆發動效！

#### 2. 小螢幕輪盤可視化佈局設計 (解法)
- **視覺挑戰**：135×240 小螢幕若塞下完整 37 格圓形輪盤，每個號碼將小於 2×2 像素，根本無法看清。
- **高質感局部可視化解法**：
  1. **動態旋轉期（水平動態刻度帶）**：
     - 螢幕中央採用「橫向號碼帶 (Number Strip)」如同高級拉霸輪盤由左向右極速飛馳。
     - 號碼帶具備實體格子背景色（紅底白字、黑底白字、綠底白字）。
     - 兩側具備動態漸層半透明遮罩，營造圓弧景深立體感。
  2. **減速與落球期**：
     - 轉速模擬真實物理摩擦力（指數衰減減速），每劃過一格指針便伴隨震動與音效。
     - 最終平滑停在中央游標指針處（▲）。
  3. **定格揭曉期**：
     - 中央開出大號牌，直接呈現超大號碼與醒目底色（如 `27 RED`）。
     - 下方顯示附加屬性：奇數/偶數（ODD / EVEN）、前半/後半（1-18 / 19-36）。

#### 3. 介面與操作
- **押注選擇**：搖桿左右撥動切換押注（`ALL` 自由模式 / `RED` / `BLACK` / `0 GREEN`）。
- **起轉操作**：
  - 搖桿用力向後拉再放開（模擬拉桿發射）。
  - 或按下搖桿中心鍵 / 正面 Button A 起轉。
- **RGB 氛圍燈**：旋轉時高頻紅綠黑跑馬流光；停在綠色 0 亮翠綠極光，停在紅色亮熱情紅光，停在黑色亮冰河冷白光。
- **蜂鳴器**：旋轉時發出擬真「嗒嗒嗒嗒嗒...嗒...嗒......叮！」的高頻齒輪卡榫聲。

## 4. 全域操控與系統選單 (System Navigation)

四款遊戲整合於同一套掌上型作業架構中，具備統一且直覺的切換邏輯：

```
                    [電源開機]
                        │
                        ▼
            ┌───────────────────────┐
            │   全域主選單 (OS Menu)  │ <─── 任何遊戲中長按 Button B (0.5秒)
            │  旋轉卡片式圖標導覽   │
            └───────────┬───────────┘
     ┌──────────┬───────┴───────┬──────────┐
     ▼          ▼               ▼          ▼
 🎲 骰子盒   🃏 幸運撲克     🎱 八號球   🎡 俄羅斯輪盤
 (Dice)     (Poker)         (8-Ball)   (Roulette)
```

### 4.1 全域按鍵指派矩陣
| 操作輸入 | 主選單狀態 | 遊戲運行狀態 |
| :--- | :--- | :--- |
| **搖桿左右 (Joy X)** | 翻頁切換四款遊戲卡片 | 調節遊戲內參數（面數、押注、語言） |
| **搖桿上下 (Joy Y)** | 切換背光亮度 / 聲音開關 | 調節數值（骰子數量、翻牌推牌） |
| **搖桿中心鍵 (Joy Push)** | 確認進入選中遊戲 | 核心動作（擲骰、翻牌、起轉、確認） |
| **按鍵 A (Button A)** | 確認進入選中遊戲 | 核心動作（同搖桿中心鍵，適合單手大拇指按壓） |
| **按鍵 B 短按 (Button B)** | 螢幕旋轉切換 (0° ↔ 180° 方便左右手) | 呼叫快速遊戲設定面板 |
| **按鍵 B 長按 (Button B)** | 進入待機睡眠 | **返回全域主選單** |
| **機身晃動 (IMU Shake)** | 隨機挑選一款遊戲啟動 | 體感互動（甩骰、揭牌、占卜搖晃） |

## 5. 軟體架構與燒錄整合計畫

### 5.1 專案目錄結構規劃
```
c:/laragon/www/m5stickc-withjoyc/
```

### 5.2 燒錄與建置技術選型
1. **開發環境**：建議使用 **PlatformIO (VSCode / CLI)** 或 Arduino IDE。
2. **核心依賴庫**：
   - `M5StickCPlus` (或原生 `TFT_eSPI` 搭配自訂接腳，避免巨型相依)。
   - `Wire` (主匯流排連接 MiniJoyC `GPIO 0/26`；內部 Wire1 連接 AXP192/MPU6886 `GPIO 21/22`)。
   - `M5HatMiniJoyC` (本地自帶驅動)。
3. **燒錄防呆規範**：
   - 燒錄時需確保 `GPIO 0` 不受 MiniJoyC 強力下拉干擾，正常插入連接即可進行 USB-C 燒錄。
   - 啟用雙緩衝 `TFT_eSprite` 避免 1.14" 螢幕高速動畫時產生閃爍撕裂感。
