# M5StickC Plus 與 MiniJoyC 硬體規格與開發參考手冊

本文件彙整 **M5StickC Plus** 核心開發板與 **MiniJoyC HAT** 搖桿擴充底座之硬體規格、腳位映射、I2C 通訊協議與暫存器定義，專門作為後續開發**掌上型紓壓玩具 (Stress Relief / Fidget Toy)** 的核心硬體參考依據。

---

## 1. 系統整體架構

本紓壓玩具採用「主核心 + 協同底座」的雙晶片架構：
- **主核心 (Master)**：M5StickC Plus（搭載 ESP32-PICO-D4），負責主要遊戲邏輯、LCD 彩色畫面繪製、六軸姿態運算、蜂鳴器音效控制與電源管理。
- **擴充底座 (Slave)**：MiniJoyC HAT（搭載 STM32F030F4P6），透過 I2C（位址 `0x54`）提供雙軸類比搖桿讀取、搖桿中心微動按鍵偵測、獨立 SK6812 全彩 RGB LED 效果，並自帶 200mAh 鋰電池輔助供電。

```
+-------------------------------------------------------------+
|                      M5StickC Plus                          |
|  [ESP32-PICO-D4 240MHz]                                     |
|  ├── 1.14" 135x240 ST7789v2 TFT LCD (視覺動畫/UI)           |
|  ├── MPU6886 6軸 IMU (晃動/傾斜/手勢偵測)                  |
|  ├── 無源蜂鳴器 Passive Buzzer (機械敲擊聲/音效)             |
|  ├── AXP192 電源管理 + 120mAh 鋰電池                        |
|  ├── Button A (正面大鍵) & Button B (側面功能鍵)            |
|  └── 頂部 8-Pin HAT 擴充槽 (I2C 通訊)                       |
+------------------------------┬------------------------------+
                               │ I2C Bus (SDA: G0, SCL: G26)
+------------------------------┴------------------------------+
|                       MiniJoyC HAT                          |
|  [STM32F030F4P6 協同處理器 @ I2C 0x54]                     |
|  ├── 雙軸類比搖桿 (XY軸 最大偏角 23°, 10kΩ, 8/10/12-bit)    |
|  ├── 搖桿中心按鍵 (Click Switch)                            |
|  ├── SK6812 3535 全彩 RGB LED (動態氛圍光/按壓回饋)         |
|  └── 內建 200mAh 鋰電池 (增加掌上型便攜續航)                |
+-------------------------------------------------------------+
```

## 3. MiniJoyC HAT (SKU: U156) 硬體規格

### 3.1 主要規格參數
| 項目 | 規格參數 | 備註說明 |
| :--- | :--- | :--- |
| **內建微控制器** | STM32F030F4P6 (ARM Cortex-M0 @ 48MHz) | 負責採樣搖桿 ADC、驅動 RGB LED、處理 I2C 通訊 |
| **通訊介面** | I2C Slave 通訊，預設位址 `0x54` | 預設速率 100kHz ~ 400kHz |
| **操作搖桿** | 雙軸類比搖桿 (總阻值 10kΩ) | 各方向最大偏角 23°，內含中心按鍵 |
| **全彩氛圍燈** | SK6812-3535 RGB LED (1 顆) | 支援 24-bit (RGB888) 色彩控制 |
| **內建輔助電池** | 200 mAh 聚合物鋰電池 | 搭配 StickC Plus (120mAh)，總容量達 320mAh |
| **外接擴充口** | 1 × HY2.0-4P (I2C 通訊接口) | 方便串接其他 Grove / Unit 模組 |
| **外型尺寸與重量** | 81.1 × 36.0 × 24.0 mm，重量約 20.6g | 雙手持握符合人體工學，握感扎實 |

### 3.2 I2C 暫存器映射手冊 (Register Map @ 0x54)

MiniJoyC 內部 STM32 韌體已將搖桿採樣、濾波與校正處理完畢，主機（ESP32）透過 I2C 直接讀取暫存器：

| 暫存器位址 | 暫存器名稱 | 長度 (Bytes) | 讀寫屬性 | 功能說明 |
| :--- | :--- | :--- | :--- | :--- |
| `0x00` | **ADC_X_REG** | 2 | R (唯讀) | 搖桿 X 軸原始 12-bit ADC 數值 (0 ~ 4095，低位元在前) |
| `0x02` | **ADC_Y_REG** | 2 | R (唯讀) | 搖桿 Y 軸原始 12-bit ADC 數值 (0 ~ 4095，低位元在前) |
| `0x10` | **POS_X_10BIT** | 2 | R (唯讀) | 經過校正的 X 軸 10-bit 位置值 (0 ~ 1023，中心約 512) |
| `0x12` | **POS_Y_10BIT** | 2 | R (唯讀) | 經過校正的 Y 軸 10-bit 位置值 (0 ~ 1023，中心約 512) |
| `0x20` | **POS_X_8BIT** | 1 | R (唯讀) | 經過校正的 X 軸 8-bit 位置值 (0 ~ 255，中心約 128) |
| `0x21` | **POS_Y_8BIT** | 1 | R (唯讀) | 經過校正的 Y 軸 8-bit 位置值 (0 ~ 255，中心約 128) |
| `0x30` | **BUTTON_REG** | 1 | R (唯讀) | 搖桿中心按鍵狀態：`0` = 未按下，`1` = 按下 |
| `0x40` | **RGB_LED_REG** | 3 | W (唯寫) | SK6812 RGB 色彩：格式為 `[Red, Green, Blue]` (各 1 Byte) |
| `0x50` ~ `0x5B` | **CAL_REG** | 12 | R/W | 搖桿六組校正參數 (各 2 Bytes)：X_min, X_max, Y_min, Y_max, X_cen, Y_cen |
| `0xFE` | **FW_VER_REG** | 1 | R (唯讀) | STM32 內部韌體版本號 |
| `0xFF` | **I2C_ADDR_REG**| 1 | R/W | 變更 MiniJoyC 的 I2C 設備位址 (預設 `0x54`) |

## 4. 關鍵資源與腳位衝突防呆指南

在 M5StickC Plus 與 MiniJoyC HAT 整合時，有以下數點硬體限制與衝突防呆必須遵守：

### 4.1 雙 I2C 匯流排分工 (重要)
- **內部 I2C (Wire1)**：
  - 接腳：`SDA = GPIO 21`, `SCL = GPIO 22`。
  - 掛載元件：AXP192 (`0x34`)、MPU6886 (`0x68`)、BM8563 (`0x51`)。
  - 初始化：`M5.begin()` 自動初始化或 `Wire1.begin(21, 22)`。
- **頂部擴充 I2C (Wire)**：
  - 接腳：`SDA = GPIO 0`, `SCL = GPIO 26`。
  - 掛載元件：MiniJoyC HAT (`0x54`)。
  - 初始化：`Wire.begin(0, 26, 400000)` 或使用 `M5HatMiniJoyC::begin(&Wire, 0x54, 0, 26, 400000)`。
  - **防呆重點**：切勿將內部元件與 MiniJoyC 混在同一條 Wire 匯流排上，必須雙匯流排分開獨立操作。

### 4.2 GPIO 0 與 SPM1423 麥克風之引腳共用
- M5StickC Plus 內建 SPM1423 麥克風的時脈腳 (CLK) 連接至 `GPIO 0`。
- 頂部 HAT 槽的 I2C SDA 也使用 `GPIO 0`。
- **開發結論**：
  - 當連接 MiniJoyC HAT 並進行 I2C 通訊時，**無法同時啟用 PDM 麥克風採樣**。
  - 紓壓玩具若以搖桿、按鍵、六軸體感、蜂鳴器與螢幕為核心，應全力優先確保 I2C 通訊穩定；若要使用吹氣紓壓模式，需切換腳位工作模式。

### 4.3 GPIO 36 與 GPIO 25 之互斥設定
- StickC Plus 內部電路設計中，`GPIO 36` 與 `GPIO 25` 共用同一個內部通道。
- 若程式中需使用 `GPIO 36` 作為 ADC 採樣，必須強制將 `GPIO 25` 設定為浮空（無上下拉）：
  ```cpp
  pinMode(36, INPUT);
  gpio_pulldown_dis(GPIO_NUM_25);
  gpio_pullup_dis(GPIO_NUM_25);
  ```
